LogSecretRedactor

@RestrictTo(value = [RestrictTo.Scope.LIBRARY_GROUP])
object LogSecretRedactor

Replaces secrets in SDK log messages.

Sensitive HTTP header values, the string values of sensitive JSON body keys, and secrets registered with registerSecret or registerPushToken are shortened to their last four characters. JWTs elsewhere in the message and the DUST auth query parameter are replaced with REDACTED_PLACEHOLDER.
