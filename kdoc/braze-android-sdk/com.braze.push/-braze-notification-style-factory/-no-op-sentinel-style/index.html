NoOpSentinelStyle

private class NoOpSentinelStyle : NotificationCompat.Style

A sentinel value used solely to denote that a style should not be set on the notification builder.

Example usage would be a fully custom RemoteViews that has handled rendering notification view without the use of a system style. Returning null in that scenario would lead to a lack of information as to whether that custom rendering failed.
