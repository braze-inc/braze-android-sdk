braze-android-sdk/com.braze.support.logging/LogCategory

LogCategory

@RestrictTo(value = [RestrictTo.Scope.LIBRARY_GROUP])
enum LogCategory(val tag: String) : Enum<LogCategory>

Functional area of the SDK that a log line belongs to.

Pass tag as the tag of BrazeLogger.brazelog(tag, …) so logs can be filtered by feature (adb logcat -s Network) instead of by an obfuscated class name. Names match the OSLog categories of the Swift SDK, except STORAGE and EVENT_BUS, which exist only on Android.

Changing a tag is a behavior change for integrators who filter on it.
